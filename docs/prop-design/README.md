# Prop-design context

PDS resolves the exact non-archived prop design category in the canonical
`group.art-design` Master Concept alongside the exact `expression` visual
style and visual prohibitions. The provider accepts only those two pinned
sources and explicit request intent. Their live contents are never bundled
into the release.

The example JSON and Markdown in this directory are synthetic fixtures for
`tests/prop-design-image-join.test.mjs`; do not submit them to a live service.
See [the official workflow contract](official-image-workflow.md).
